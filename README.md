## Run Locally

1. Clone the repository
2. Run `npm install`
3. Run `npm run dev`
4. Open `http://localhost:5173` in your browser

## Project Structure

- `index.html` - main HTML file
- `src/` - React source files
- `package.json` - scripts and dependencies
- `.gitignore` - ignores node_modules and dist
